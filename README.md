# 猜一球 · NBA 球员猜谜

个人休闲试玩。自由换题、8 次猜测、中文搜索和放弃本局。

本版沿用现有正式名单：简单 150 人、困难 206 人、历史 276 人；猜测池 5155 人。没有采用全明星 A/B/C 模拟方案。

数据为 2026-11-15 本地数据库导出的静态快照，并非实时更新。生涯统计主要截至 2025–26，现役名单采用项目的 2026–27 快照。部分属性存在缺失或争议，尚未完成全库事实核验。

玩家资料参考 NBA Stats.net、NBA 官方资料、Wikidata 等既有来源，中文姓名包括已有通用译名和待审核音译。头像由 NBA CDN 提供。本项目与 NBA 无官方关联。本仓库没有包含原始 SQLite、XLSX 或压缩数据包，不对第三方资料额外授予授权。

静态前端包含游戏所需球员信息和答案池。进度保存在访问者自己的浏览器中。
